1. Research Question

Define the scope of your inquiry before manipulating the virtual space. This information frames every subsequent module.

Study Definition

Research Type

Positioning

This laboratory is a virtual experimental research instrument for exploring relationships between public-space design variables and model-based environmental and behavioral indicators. It supports exploratory research, parametric studies, scenario comparison, controlled simulation, research-instrument prototyping, and observation / participant-response data collection.

It does not constitute a peer-reviewed validated instrument, a scientifically proven predictor, or a real-world behavioral simulator.

Key Concepts (Glossary)

      

        
Model-based indicator

        
A computed 0–100 score from a transparent, inspectable formula (see any "View Calculation" button). It estimates modeled potential under stated assumptions — not a measured real-world value.

        
Baseline / Treatment

        
A controlled-experiment pair. Treatment starts as an exact copy of Baseline; you then change only the independent variable, so any difference in indicators can be attributed to that one change.

        
Locked control variables

        
Variables you've committed to keep identical between Baseline and Treatment (e.g. geometry, entrances, lighting) so they can't confound the comparison.

        
Trial

        
One computed run of an indicator for a condition. In deterministic mode, repeated trials of the same condition give identical values — enable "stochastic simulation" (Experiment → Replication) to add synthetic trial-to-trial variation.

        
Replication

        
How many trials are run per condition in a controlled experiment. More replication gives sturdier descriptive statistics (mean, SD) for each condition.

        
Condition

        
One named, hand-built space configuration you want to compare against others (Experiment → Multi-Condition, up to 10).

        
Population

        
A larger batch (e.g. 10–50) of independently randomized layouts (Space Builder → Random Population Generator), used as a broader sample for correlation and exploratory analysis rather than a single hand-picked comparison.

        
Effect size (SMD)

        
Standardized mean difference between two conditions' trial values. It needs variance to be computable — either stochastic simulation or several distinct trial values.

        
Correlation vs. causation

        
A Pearson r describes an association within this simulated/model-generated dataset only. It never, by itself, proves that one variable causes another.
